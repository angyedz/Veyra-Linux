# Veyra Linux 0.1.0-alpha.1

> **Release-note draft.** Do not publish this page or attach an ISO until the build, boot, install and graphical Calamares/Plasma checks pass. Then update this page with final evidence and the exact artifact checksum.

## What this preview contains

Veyra Linux is an experimental Alpine Linux 3.22 desktop image for x86_64. The current installation creates one conventional Alpine system root with KDE Plasma, SDDM and OpenRC. It includes a guided Calamares installer with a text fallback, firmware and graphics package selection, native Telegram Desktop, and Veyra AppCenter for per-user Flatpak applications such as Discord.

An internet connection is required during installation to download the desktop, firmware and bootloader packages. NVIDIA uses the open-source Nouveau driver. The current automated install qualification uses QEMU; physical PC and GPU compatibility has not been established.

## Known limitations

- This preview does not implement the planned separate system and user Linux environments. User accounts and applications run in the conventional installed system.
- Atomic system updates, user-network VPN isolation, SnapCore snapshots, Guardian and independent recovery are not shipped.
- The clean-disk QEMU workflow runs Veyra's installer shell steps. Calamares graphical clicks and first Plasma login must be qualified separately before publication.
- Only the tested x86_64 QEMU boot and installation path may be claimed as verified. Back up important data and try this alpha in a disposable VM.
