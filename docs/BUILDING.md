# Building Veyra Linux

Veyra's ISO is produced by Alpine's `aports/scripts/mkimage.sh`, with a custom profile in `images/mkimg.veyra.sh` and a live overlay generated by `images/genapkovl-veyra.sh`.

## CI

Pushes to main trigger the **Veyra ISO** workflow whenever the image or installer changes. Successful builds publish the ISO and its checksums as GitHub Actions artifacts, then boot the image under QEMU for a basic serial-console check.

## Local build

Use a disposable Alpine 3.22 x86_64 environment with network access, sufficient disk space, and root privileges:

```sh
git clone https://github.com/angyedz/Veyra-Linux.git
cd Veyra-Linux
sh scripts/build-calamares.sh
sh scripts/build-iso.sh
```

Output is written to `dist/`.

The ISO is a graphical KDE Plasma/Wayland live system. Its root is loaded into RAM on boot, while the read-only installation medium supplies the APK cache and kernel modules. See [Live environment](LIVE.md).

## Validation

```sh
sh tests/static.sh
sh scripts/test-iso.sh dist/veyra-linux-*.iso
```

The ISO is still a **development build**. The glenv upstream installer is available through `veyra-setup` but is not baked into this live ISO. The ISO build requires a successfully compiled native Calamares package in `dist/calamares/`; Calamares is bundled from the local signed APK repository. Complete end-to-end installation on a blank QEMU disk remains unverified.
